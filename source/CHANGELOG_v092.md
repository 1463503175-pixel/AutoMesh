# v0.9.2 修复清单

| 类别 | 旧版缺陷 | 本次修复 | 验证 |
|---|---|---|---|
| 连接 | PyWorkbench 连接成功，但系统列表脚本可能返回 NoneType | 属性容错、JSON 解析保护，临时文件回退 | 缺失 DisplayText / None / 'None' / 本地文件回退模拟 |
| 安全 | `SendCommand` 脚本返回标记不是规范 JSON | 改成 JSON，应答未知不自动重发 | 模拟只调用一次 |
| 连接配置 | 默认 mtls 导致无证书时报错 | 仅本机默认 insecure，仍可手选 mtls | 参数及代码审查 |
| 界面 | 页内文字和输入框/按钮重叠 | 统一控件布局图、逐页调整文本 y 坐标 | 不同窗口宽度下纯几何重叠检测 |
| 错误追踪 | 错误堆栈不可见 | 保存 `last_workbench_error.log` | 源码及构建检查 |

**限制：尚未在真正的用户 Windows 2024 R2 工作台执行。此版本重点修复连接与基础布局，非 ALD 自动优化闭环成熟版。**
