# AutoMesh v0.10.8 · 操作说明

**要求**：Windows x64、已安装 ANSYS Workbench / Meshing 2024 R2、Python 及 PyWorkbench，使用现有工程而非另起 Workbench。所有控制通过现有会话脚本接口执行，不使用截图识别坐标或鼠标宏。

## 一分钟操作

1. 打开现有 Workbench + 目标 Meshing，命名入口 `inlet` 与出口 `outlet`。
2. 打开 `AutoMesh.exe`，自动发现并连接已监听的 Workbench 脚本服务。如服务尚未启动，需在**现有 Workbench** 的 Scripting 命令窗口执行 `StartServer()`，再点击自动连接。不得重启/新建工程替代。
3. 在概览页点击 **只读扫描**。扫描会读取当前 Meshing 的 Named Selection（不修改已有网格），自动计算**初步推荐尺寸**及相近尺寸的设置分组。
4. 在局部细化页，左侧点 **▼ 分组** 可以展开、双击可折叠。选中**组标题**，右侧“启用整组”、输入**整组尺寸**并点击“整组设置”统一设置该组。选中**单个命名**，使用“启用此命名组”“单项尺寸”“保存单项尺寸”只改当前项。
5. 所有尺寸单位 mm。点击**自动推荐并归组**会重置本页未发布的人工草稿（先确认）。同一几何的只读刷新可保留人工设置。`inlet/outlet` 不进入自动推荐。
6. 读完预算预览；若有重叠面应取消重复选择。点击**按命名发布 Sizing**（需确认）才会调用 ANSYS 原生 `AddSizing` 并以已有 Named Selection 绑定；**不执行 GenerateMesh、不删除已有网格、不改全局 ElementSize**。已有同名/已关联 Sizing 保留人工修改。
7. 在 Meshing 中检查实际 Sizing 作用域、尺寸、网格状态。若当前已有网格，修改 Sizing 可能令它失效；软件不会自动重划。确需重新划分时只在经过审核的可操作模型上单独确认。
8. 质量报告页先点 **只读检查网格质量**；失败/警告元素由各自按钮分别调用 ANSYS Quality Worksheet 原生 API。Worksheet 需要在 Meshing 中先计算/刷新，0 个失败是正常结果，不代表全部网格质量合格。**辅助风险抽样**最多抽样 6000 个四面体单元，不得把无样本当作全网格无风险。

## 软件不会做的事情

不会自动启动另一个 Workbench/Meshing，清除原有网格，初始化 Fluent，改动 `inlet/outlet`，将未知质量指标用估计值补全。软件无法从未启动的脚本服务凭空读取端口。

## 验收边界

Linux 中已完成 Python 与 Go 离线测试、Windows PE x64 编译；但没有访问你的 ANSYS 2024 R2 工作站进行端到端实测。首次请只完成“扫描→审核建议→发布一组 Sizing→在 Meshing 树中验证”，先不要重划现有 1809 万单元网格。


## v0.10.8 重要修复（2026-11-07）

- 【启用整组】状态点击后立即更新当前方案；切换组选项不会清除勾选，停用后保留原有每项尺寸，重新启用时恢复。
- 中文化或手工重命名后，旧命名仅在与**唯一一个**当前命名组的全部面 ID 完全一致时重新绑定，使用原提交名读取单项尺寸，绝不靠名称模糊猜测。
- 重新只读扫描后，若几何指纹一致，可以对用户已经编辑的尺寸进行唯一面范围匹配、保留人工配置；几何更换或不唯一时不自动匹配。
- 发布前预先列出所有丢失/歧义命名，避免已经创建部分 Sizing 后才因下一组错误中断；若同名命名组作用面发生变化，也拒绝沿用旧扫描记录。
- 已有 inlet/outlet、用户 Named Selection、现有网格及原来的 Sizing 均不删除、不覆盖。

操作：关闭旧 AutoMesh，运行新版并**只读扫描**当前 Meshing，再进入局部细化检查组状态。8 mm 组不需要删除，只需取消启用。勾选应在切换和再次查看后保留。然后只选择一个确认作用面正确的命名组试验【按命名发布 Sizing】，不要先点击网格生成。

本次所有运行测试仅限离线/模拟 ACT 与 Windows 交叉编译；不能代替在你的当前 ANSYS 2024 R2 会话中的实际运行验收。

## v0.10.8 · `parameterized and is read-only` 定向修复

- 若新建 Sizing 在设置 `ScopingMethod` 时被 ANSYS 拒绝，优先尝试设置 `NamedSelection` 让 ACT 自己选择 Component 模式，并验证二者回读。
- `ElementSize` 在设置作用域之前写入并回读；只读异常会指出具体字段（Name / ElementSize / NamedSelection / ScopingMethod），不再只弹出通用英文错误。
- 不允许悄悄改为“直接面 ID”控制来冒充 Named Selection 绑定。
- 新建 Sizing 出错时只尝试清理本次刚创建的对象；不清除已有网格、已有 Sizing 或 Named Selection。
- **仍需实机确认：** 若当前 ANSYS 会话连 `NamedSelection` 和 `ScopingMethod` 都拒绝修改，AutoMesh 会安全停止并提示具体字段。应在 Meshing 中核实是否有参数化或编辑器锁定，而不是让程序强行解除。

参见 `R7.5_分簇优化及验收.md`。不再因总标记数量超过 64 一次性否决 297 个高偏度单元；发布前必须审核球形影响域及晶圆间隙，不自动重新划分。
