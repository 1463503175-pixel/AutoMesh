# AutoMesh v0.10.1 更新（2026-11-06）

1. **通用几何面识别**：替换新工作流的“孔壁/狭缝”功能假设，改为全模型面面积排序、相近面积分档、面型与所属体分组。零散大平面列为审核候选，默认不细化；重复大面保留候选。保留旧版 legacy API 仅用于兼容测试，界面上的新发布流程以面积分组为准。
2. **候选列表可解释**：显示组编号、面积类别、面类型、面数；选中后显示面积范围 mm²、建议尺寸 mm，明确是几何候选，不直接猜测物理用途。
3. **进度与状态**：ACT 在读取几何面时按已读取面数发阶段百分比；当前阶段进度、详情在所有页面左边栏常驻，概览页有进度条。新建每任务唯一进度侧文件，Go 并行轮询，避免 SendCommand 同步等待导致“卡住”。ANSYS GenerateMesh 阶段无法精确读进度，明确显示不确定状态与任务耗时，不伪造百分比。
4. **风险单元诊断可追溯**：诊断结果在 HTML 报告靠前独立展示，包含有官方质量失败/警告计数时的统计、采样数量、Element ID、坐标、采样覆盖率，并导出 `risk_samples.csv`。即使无风险采样，也写明局限；官方失败单元的 Meshing 标记仍需独立确认。
5. **安全性**：保留既有网格保护、进出口校验和独立发布命名 / Sizing / 生成网格流程。不自动清理网格，也不把样本四面体代理误报为 Fluent OQ。
6. **测试**：更新 3 项原依赖旧“Gap”分类的测试，以验证新面积工作流中的同等隔离与尺寸范围保护；加入 v101 分类、进度和报告回归测试。

**待真实 ANSYS 验收：** 复杂流体域上的面积分类质量、Named Selection 原生创建/高亮、长时运行进度文件更新、Worksheet 实际统计与官方失败元素组创建，以及 Fluent 中的最终网格质量。
