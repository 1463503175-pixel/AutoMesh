# AutoMesh 2024 R2 v0.10.5 — 智能局部细化与质量诊断修复

## 本轮已修改

1. **已有命名→自动建议**：扫描当前 Meshing 的 Named Selection 和真实几何面；通过面面积中位数、解析曲面比例与当前实际全局尺寸给出保守的初步建议，`inlet/outlet` 保留不参与自动细化。面积仅是候选尺度，不保证功能或最终网格质量。
2. **按相近推荐尺寸分组**：左侧列表支持展开/折叠分组；每项独立启停并填写尺寸；整组选中后可一次启用/停用并设置尺寸；整组操作会明确覆盖子项，普通单项操作不影响其他项。
3. **刷新保留人工设置**：同一工程和几何指纹未变化时，保留已手动编辑过的启用项与尺寸；几何变化时不复用旧设置。
4. **预算预览**：展示本页选中 Named Selection 的表面积/尺寸²代理值、重叠面数和贡献最大的组；这不是实际网格单元数或内存预测，真实发布还执行 ANSYS 端保守资源门禁，连同既有人工 Sizing 一起核验。
5. **失败/警告元素分离**：新增“标记警告单元”；官方 Worksheet 失败数为 0 返回正常、说明未创建组；未取得 Worksheet 接口则明确返回不可用，而非抛出误导性 Traceback。使用官方 `CreateMQVolumeElementsNamedSelection` 的失败 `1`／警告 `0` 代码（如当前 ACT 版本支持）。
6. **质量报告**：用 Worksheet 失败与警告计数替代几何候选假质量卡；增加节点数、Skewness 最小/平均/最大值、数据来源说明，以及独立的官方定位操作结果；`未获取` 不会伪装成通过；不再将非质量任务覆盖既有质量 HTML。
7. **可用性**：常驻任务进度沿用原生的阶段进度/耗时提示，按钮新 ID 已接入事件与任务白名单；局部细化两栏布局静态碰撞测试覆盖多种窗口宽度。

## 必须实机确认的限制

- 当前环境无法运行 Windows ANSYS 2024 R2，未验证新增的分组控件实际外观、ACT Worksheet 警告组创建及某些 API 回写能力。
- 内存预算只是保守代理，32 GB 机器仍可能因复杂几何或实际体网格规模不足而失败。
- 自动建议尺寸并非经过网格独立性研究或正式质量验收，必须在 Meshing 审核位置/尺寸后再生成。
- `Orthogonal Quality` 在此 ACT 安装版本若不暴露，不可使用其他指标伪造；需在 Fluent 核验。
- 目前仅自动探测**已启动**的 Workbench 脚本服务，不会自行启动一个新的 Workbench；无监听端口时须在原 Workbench 执行 `StartServer()`。
