# AutoMesh v0.10.1 功能对齐复查

| 用户需求 | 当前实现 | 证据类型 | 仍需验证 |
|---|---|---|---|
| 与 ALD 无关的通用面面积排序、分类与集合 | 新工作流已替换功能型猜测 | 纯 Python 算法测试 | 真实多体/曲面复杂几何 |
| 不细化整块匀气挡板大平面 | 零散大平面默认“审核关闭” | 面积分布合成测试 + GUI 开关 | 原生面积是否与 Meshing 显示一致 |
| 重复的大面保留候选，避免漏晶圆 | `area_repeated` 预留候选名额 | 面积合成测试 | 是否与具体晶圆表面一一对应 |
| 分组可看懂 | 组编号 + 面型 + 面数，下面面积范围 mm²/建议 mm | Go 源码与静态测试 | Windows 125%/150% DPI 下是否截断 |
| 在 Meshing 中命名、Sizing 独立可编辑 | 复用 v0.9.10 的 AM_*/AutoMesh_* 实现 | 模拟 ACT 及已有用户实机截图（旧版仅发布命名） | v101 新面积分组发布实机结果 |
| 显示百分比和执行内容 | 读取面数等可计量阶段显示百分比，长时 GenerateMesh 显示不确定并持续心跳 | Python + Go 测试 | Workbench SendCommand 真实阻塞期间实际 UI 更新 |
| 风险单元“在哪里” | HTML 近顶部显示风险定位清单和 CSV；可显示官方失败计数 | Go 报告单测 | 网格元素坐标接口/官方 Worksheet 2024 R2 实机 |
| 只需 inlet/outlet 手工边界 | 保留边界硬校验；其他命名可复用 | 模拟 ACT | 有特殊边界的模型需人工处理 |
| 32GB 保护、保留现有网格 | 沿用网格不覆盖及尺寸预算；仅代理估算 | 回归测试 | 不能精确预测内存和单元数 |

**未完成的能力：** 面分类结果随 CAD 改版的可靠自动迁移；将采样的坏单元自动且完整地对应回几何局部 Sizing；对所有网格元素计算官方最差质量；真实 ALD 一键划分质量验收。这些不能凭本版离线测试宣称已完成。
