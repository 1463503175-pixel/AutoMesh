# AutoMesh R8.0.1：任务回执与进程状态修复

本补丁基于用户提供的 R8.0 完整源码，仅修复任务执行可靠性；不改动偏度区间标记、空间分簇、候选排序、人工勾选、Sizing 安全审核及增量发布规则。

## 修复内容

1. **ACT JSON 回执写入**：Windows/IronPython 写入器不再将 `None` 作为 `File.Replace` 的备份文件参数。替换现有回执时先使用同目录真实备份路径；若原子替换不可用，则采用“旧文件移至备份 → 新文件移入 → 失败时恢复旧文件”的可恢复流程。新建回执使用 .NET `File.Move`。任何失败都会保留具体异常，不会先删除旧结果。
2. **Meshing 进程状态探测**：`OpenProcess` 同时申请 `PROCESS_QUERY_LIMITED_INFORMATION` 与 `SYNCHRONIZE`，满足后续 `GetProcessTimes` 和 `WaitForSingleObject` 的权限要求，避免因句柄权限不足产生误报 `Access is denied`。
3. **旧任务安全恢复**：识别 R8.0 Worker 在执行操作后明确写出的“终态结果全部写入失败 / 部分回执写入失败”阶段标记。标记稳定超过 10 秒后，只恢复为 `error` 终态并释放旧任务锁；绝不伪造 `ok`，也不据此认定预览或发布成功。这样可避免旧回执故障永久阻止 R8.0.1 更新。
4. **版本标识**：界面标题和诊断版本更新为 R8.0.1。R8.0 原有功能和安全边界保持不变。
