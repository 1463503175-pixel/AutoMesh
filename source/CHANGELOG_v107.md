# AutoMesh 2024 R2 v0.10.7 — 组启停持久化和命名重绑定修复

## 实际修复
1. Win32 复选框事件按窗口句柄触发，不依赖默认的 0 控件 ID：勾选立即保存。切换其他组不会丢状态；关闭再启用保留单项尺寸。
2. ACT 按命名发布时对旧名做精确面 ID 集合匹配，只接受唯一目标。通过中文翻译或手动改名后使用原始配置键读取尺寸；成功则将名称写入执行摘要。
3. 发布预检查汇总多项缺失或歧义命名；面作用域与旧扫描不一致则阻止发布，禁止误绑定。
4. Go 刷新扫描时保留同几何下唯一精确面范围的手动尺寸设置；发布成功后同步当前界面内的别名。
5. `inlet/outlet`、已有网格和人工设置保持不变；发布 Sizing 不清网格、不调用 GenerateMesh。

- Python 及 Go 模拟和单元测试通过，Windows x64 EXE 已交叉编译。
