# R6.3.2 自动 StartServer 调整

- AutoMesh 启动、内部脚本校验成功后，**自动调用已有的连接流程**，不再要求点击“自动查找并连接”。
- 优先复用已经启动的 Workbench 脚本服务；仅未找到时尝试在当前唯一 Workbench GUI 命令窗口执行 `StartServer()`，随后核验端口和 Mesh 系统。
- 只使用 Windows UIAutomation 控件接口，不使用图像坐标、不启动第二个 Workbench、不修改几何/网格。
- 如果 Workbench 不存在、命令窗口不可唯一识别、权限不足或初始化失败，显示诊断，不会重复发送命令；仍可手动点击连接按钮重新检查。
- 自动连接失败不再启动时弹出模态窗口阻塞操作。

**验证限制：本环境无法连接用户的 Windows ANSYS 2024 R2 实机，自动命令注入的 UIA 路径仍需要现场确认。**
