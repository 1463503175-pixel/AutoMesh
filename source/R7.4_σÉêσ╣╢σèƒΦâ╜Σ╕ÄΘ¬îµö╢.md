# AutoMesh R7.4 合并功能与验收

## 合并内容

1. 质量报告增加可编辑 Skewness 下限和上限（默认 0.90～1.00），按钮“标记所选范围”。
2. Meshing Worker 创建独立 Mesh Element Named Selection；数据来自当前网格的原生 Worksheet 指标，不依据默认 warning=0 判定无目标。支持双端区间，接口不兼容时拒绝冒充正确结果。
3. 标记记录保存工程、几何指纹、网格单元数、Named Selection 对象 ID 和完整选中 ID；生成警告区方案、查看具体范围、审核发布 Sizing 共享经核验的标记。旧网格和旧对象失效时拒绝发布。
4. StartServer 自动连接：先寻找并验证现有服务；不能仅凭 Workbench 存在 TCP 监听端口就假定服务已启动。未验证到服务才通过 Windows UIAutomation 对**已打开** Workbench 的唯一命令窗口提交 StartServer()，然后扫描端口再次验证。
5. Workbench 连接验证以真实 list_systems 为准，不尝试新建 Workbench，也不使用截图坐标点击；自动识别失败时给出诊断，不盲目重试或覆写用户命令。

## 验证结果与限制

- Python unittest 192 项通过；Go 测试通过；Windows amd64 GUI PE 编译成功。
- 以上为离线模拟/编译验证，不是 ANSYS 2024 R2 实机验收。
- 不同版本 ACT 对 Mesh Element / Skewness Worksheet 操作符的支持不同；缺失时可能不能成功标记，程序会拒绝产生伪造结果。
- 自动执行 StartServer() 依赖当前 Workbench GUI 的可访问性元数据与命令输入控件。若命令窗口不暴露唯一可编辑控件或 RPC 不匹配，将停止并提示；不能保证所有安装环境均无需人工操作。
- “生成警告区方案”只是可审核候选；“审核发布 Sizing”创建局部尺寸控制，但不会自动重划网格、保证偏度降低或完成多轮优化。现有自动多轮闭环仍未实机验证。
- 对于超过 50,000 个符合范围的网格单元，本版拒绝创建自动标记，以保护 32 GiB 设备。

## 使用

1. 保存 Workbench 工程，关闭旧 AutoMesh，保留 Workbench / Meshing 会话。
2. 解压新包到英文路径，运行 AutoMesh.exe。确认自动连接；如失败，请查看详细连接诊断。
3. 在“质量报告”页输入偏度范围（默认 0.90～1.00），点击“标记所选范围”，确认实际单元数量与创建的 Named Selection。
4. 点击“生成警告区方案”，查看其范围和排除原因；需要修改 Meshing 时才点击“审核发布 Sizing”。发布前先核实当前工程和网格状态。
5. 重新划分网格必须单独经用户确认，且生成后需要重新计算质量并重新标记偏度单元。

不要把 Worksheet 警告数 0 视为没有高偏度单元；也不要把偏度最大值等同于整个质量分布。
