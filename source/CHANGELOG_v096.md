# AutoMesh 2024 R2 v0.9.6 — 保守安全修复

基于 v0.9.5 完整源代码增量修改，不修改 ANSYS 项目或工程数据。

## 修复

1. **局部细化预算**：自动生成前依据当前 CAD 单位换算后的各作用面面积，按所有启用的局部组、实际用户覆盖尺寸重新计算 `面积 / 尺寸²` 代理值，超过 1,500,000 则拦截。用户手动细化孔、狭缝和进出口均计入；同一个面不重复计数。此预算只是适配 32 GiB 内存的保守风险否决条件，**不是体网格数或实际峰值内存预测**，未保证在该预算以内必然安全。
2. **孔径分组**：重复圆柱面根据真实检测到的圆径按比例划分多个组，分别设置 Sizing，避免小孔强制大孔使用同样尺寸。对外保留“孔壁细化”总开关，报告逐组记录直径区间。圆柱面候选并非必然是匀气板通孔。
3. **重复执行与崩溃恢复**：新增 Windows 单实例互斥、跨任务独占 `active_task.json`。已结束任务自动释放，未知状态必须人工核对；“更多设置”两次确认后可归档并解除遗留任务锁。
4. **局部控制异常恢复**：默认不复用和删除残留控制。明确勾选恢复且已确认旧任务停止时，只复用名字、作用面集合、尺寸及单位完全匹配的 `AutoMesh_*` 控制；不匹配直接拒绝生成，不删除任何控制。
5. **分阶段进度与超时**：Meshing 命令进入后立即写入任务已启动；连接与派发桥接设置时限，派发已接收但未确认启动超过 75 秒即停止等待并保留任务占用，禁止直接再次提交。
6. **小问题**：首页“查看报告”正确打开质量报告页；局部细化候选按组汇总；增加异常恢复 UI；尝试使用 Windows 的 GDI 缩放 DPI 上下文，降低不同缩放比例造成的文本错位。
7. 质量报告增加资源预算、恢复复用数和圆孔直径分组。

## 使用和限制

- 用户手动在当前 Meshing 为入口/出口创建 `inlet`、`outlet` Named Selection。先连接 → 只读扫描 → 检查局部细化 → 确认生成。
- **不保证自动识别的平行面一定是晶圆片间通道，也不保证圆柱面是真实孔道**。必须检查拟采用的面作用域；细化值只作用于所识别面，不能代替物理验证。
- 仍采用现有 Workbench `Mesh.SendCommand` 通道；**单凭用户勾选“Meshing 编辑器已打开”无法验证它一定投递到前台同一编辑器**，真实工程仍需核查。
- 不修改已有网格；不启动 Fluent；不会自动修复失败网格；质量数据仍以真实 Meshing/Fluent 结果为准。
- 高 DPI、任务阶段和孔径分组的代码检查及自动测试已完成；Windows + ANSYS 2024 R2 实机会话未在本环境连接验证。
