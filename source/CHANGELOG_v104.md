# v0.10.4 修复记录

- 修正局部细化的两栏布局：滚动列表随窗口宽度调整，右侧启用、尺寸、保存区保持独立位置；新增多个窗口宽度下的文字与控件碰撞测试。
- 默认仅显示 AutoMesh 辅助命名，支持刷新与切换全部命名；刷新只在工程/几何指纹一致且名称仍存在时保存尺寸草稿。
- 修复新增质量检查与中文化任务未进入 Go 任务白名单的阻断性缺陷。
- 区分任务报告与网格质量报告：常规任务保存 activity_report.html，质量检查保存 quality_report.html；非质量任务不抹掉历史质量文件，软件显示其可能过期。
- 旧版 `AM_*` 辅助命名可经用户确认尝试转换为中文；已经被 Sizing 绑定的对象和原有 Fluent 边界不自动改名，防止破坏绑定。
- 连接页面支持自动寻找本机已启动的 Workbench 脚本服务端口；改用 127.0.0.1 避免 IPv6 ::1 的连接拒绝。只有服务已启动才能发现，不能从无端口状态自动启动。
- 加入独立进度阶段、明确的不可测指标说明；保留现有网格保护。

## 验证限制

- Python 和 Go 离线测试、Win64 编译、ZIP 完整性检查不等于真实 ANSYS Meshing 实机验证。
- 中文原生命名、Workbench 自动发现及各个 ACT 质量指标需在本机真实会话验收；缺失数据不得用推测值补齐。
