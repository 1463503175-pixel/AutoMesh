# AutoMesh v0.9.8 — 安全闭环针对性修复

## 已修复

1. 对 `inlet/outlet` 的当前真实作用面、重名、互斥、`Send to Solver = Yes` 实施生成和导出前的硬性校验。已复现并覆盖“禁用端口 Sizing 后删除 inlet 仍可生成”的旧漏洞。
2. 在“更多设置”新增明确的 `.msh` 导出按钮。导出不再依赖生成任务旁路；无网格、质量严重失败、无人工确认、存在输出文件时拒绝导出。
3. `generate_reviewed` 输出 `quality_status`（pass/warning/fail）、`quality_gate` 和独立说明。ACT 不支持正交质量时必须显示 warning。
4. 同径圆柱孔壁只有存在明显空间间距才分组，不再按面数中位数切连续阵列。
5. 在用户明确启用全局覆盖时增加体积/尺寸³的粗代理保护，维持面积/局部尺寸²代理和 32 GB 风险提示。
6. 更新界面按钮、布局重叠单元测试和 HTML 报告。

## 尚不能宣称完成

- 未在用户真实 FFF 工程中运行 ANSYS 2024 R2 ACT 原生操作，因此不能保证 Export API 在该环境可用。
- 仍未实现跨 CAD 改版后的可靠分组自动重绑定（必须人工确认）。
- AutoMesh 内尚无完整逐组编辑表；在 Meshing 树中可以逐组手动编辑。
- 内存代理不是实际内存或单元数预测；网格质量必须在 Fluent 再次验证。
