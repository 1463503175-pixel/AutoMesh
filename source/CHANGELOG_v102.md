# AutoMesh v0.10.2 修改记录（2026-11-06）

针对真实 Meshing 截图中“挖孔面被遗漏”和“字体/控件重叠”问题进行修正。

## 一、面选择算法

- 面积为主：完整扫描有效几何面的 `Id / Area / SurfaceType / Body`；几何面按实际面积大小排序，并按面积区间、面类型和所属实体组织候选。
- 取消原先按“小面积14组、重复面积10组、大平面4组”截断候选的配额；在当前规模下最多展示4096组，超过上限明确报告未展示的组/面，不谎称全覆盖。
- 所有有效面都进入面积候选库存，包括原本在 `4inch`、`2mm` 等人工 Named Selection 内的面；不修改人工命名。
- 自动建议启用的组最多24组，优先考虑重复的圆柱小面；其余组仍可见，由用户在局部细化下拉列表逐组勾选启用。
- 保持 `inlet/outlet` 原有命名不变；创建新辅助命名时不包含它们。

## 二、Meshing 原生面积选择

- 创建 `AM_*` 命名组时，优先采用 ANSYS ACT `NamedSelection` Worksheet，选择条件为 `GeoFace + Size + RangeInclude [mm²]`。
- 先在完整快照内预检查原生面积范围是否精确匹配预期面集合；创建后再次读取真实面 ID 核验。
- 如果面积范围会混入其他面、原生 Worksheet 不可用或返回不匹配，则删除不完整的新 Worksheet，并改为经精确核验的 Face ID Named Selection；报告记录方式与原因。**绝不误将多选的面作为成功。**
- `仅发布命名`不添加 Sizing、不清网格、不生成网格；发布 Sizing、审核后生成仍各自独立。

## 三、界面布局

- 四类区域由固定的重叠坐标改为85px独立行，调整提示文字、输入框、分组说明、下拉框、按钮间距。
- 修复左侧底部两行状态文本重叠，保留运行进度信息。
- 为局部细化各区域及左侧进度/状态增加几何重叠测试。

## 四、测试和限制

- 92项 Python 离线测试通过，Go单元和竞态测试通过，Windows x64 编译成功。
- 新增超过28个面积分组时完整保留候选、400孔壁+320重复面+大板样例、人工命名与区域库存共存、原生Worksheet范围核对、已有网格仅发布命名等回归。
- 仍未在用户真实 `FFF` 工程中验证 Meshing 原生 Worksheet `Generate()` 在全部目标分组上的行为，也未证明每个面积组恰好对应物理通孔；必须先核对高亮，再决定 Sizing。
