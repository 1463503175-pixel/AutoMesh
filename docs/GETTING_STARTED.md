# AutoMesh R8.1 · 新手快速上手

> 本指南面向第一次使用 AutoMesh 的 ANSYS Meshing 用户。当前版本为 **R8.1 RC（候选版）**；Windows/ANSYS 的部分原生接口仍待实机验收，正式工作前请先备份工程。

## 0. 开始前要准备什么？

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows x64 |
| ANSYS | 已打开的 Workbench / Meshing 2024 R2 |
| 工程 | 已在 Workbench 中打开目标工程，知道要操作哪个 Mesh 系统 |
| 程序 | [AutoMesh.exe](../app/AutoMesh.exe) |
| 数据目录 | `C:\ProgramData\AutoMesh2024R2\Data`；升级时保留，不要删除 |

**无需先启动 Fluent。** AutoMesh 主要通过现有 Workbench / Meshing 会话工作，不能把 Fluent 的指标读取能力当作 Meshing ACT 已验证的接口能力。

## 1. 五步完成第一次质量检查

1. **打开 ANSYS 工程。** 在 Workbench 中打开已有工程，进入目标系统的 **Meshing 编辑器**。
2. **连接工程。** 运行 AutoMesh，点击左侧 **连接工程**，连接当前 Workbench，选择正确的 Mesh 系统；确认程序顶部显示已连接。
3. **同步工程。** 点击顶部 **同步工程**，确认项目和 Mesh 系统与当前 ANSYS 一致。需要按几何 Face/Body 精确控制时，再到 **局部细化**进行完整几何扫描。
4. **检查网格。** 点击顶部 **更新质量**，打开 **质量报告**，查看最大偏度、Element Quality、单元数及数据来源。
5. **保存结果。** 在 **质量分析**查看历史记录，适当时进行前后对比；没有完整几何核验的记录只作参考对比。

> [!TIP]
> 普通“更新质量”并不等于读取全部逐单元偏度。P95、阈值计数、最小正交质量等依赖相应的原生接口；未取得时代表**无有效结果**，不是零。

## 2. 想修改网格？先选择适合的路线

### 路线 A：按已有几何命名组设置尺寸

**适合**入口 `inlet`、出口 `outlet`、挡板孔、晶圆面等已经在 Meshing 中命名的区域。

1. 打开 **局部细化**，按需要执行**完整几何扫描**，核对工程与几何身份。
2. 在命名组列表中找到目标区域。**手动命名和 AutoMesh 自动识别的区域都应纳入列表。**
3. 分别检查几何作用域、现有 Sizing 覆盖状态，以及建议单元尺寸。
4. 修改某项或整组尺寸；**入口和出口允许不同尺寸，不套用固定值**。
5. 人工选择需要发布的目标，查看冲突、失效引用提示，再发布 Sizing。
6. 回到 Meshing 控制树核对新控制；原有手动 Sizing 应得到保护。

### 路线 B：按劣质网格单元进行局部优化

**适合**局部最大偏度过高、Element Quality 太低、小凸起和短边附近出现异常的情况。

1. 先执行 **更新质量**，进入 **质量报告**。
2. 在“目标单元标记”选择 **自定义偏度区间**或 **自定义 Element Quality 区间**。
3. 输入目标区间，点击 **标记目标单元**。这会在 Meshing 中建立相应元素命名选择组，但不会 GenerateMesh。
4. 点击 **生成局部方案**，按劣质单元的位置、Body 和邻接关系形成候选。
5. 打开 **查看全部影响域**，检查球形作用范围、晶圆间隙、小特征诊断及已有 Sizing 重叠。
6. 进入 **候选审核**，勾选目标、检查预算与风险，并完成必要的人工确认后发布。
7. **由你自行决定是否在 Meshing 中重新生成网格**。重划后重新执行质量检查并比较结果。

> [!IMPORTANT]
> 单批发布上限 6 个。历史累计预算代理超过 120000 时需要额外确认，但 120000 不是实际网格单元数限制。禁止跳过几何身份、重复控制和人工审核。

## 3. 六个页面分别干什么？

| 页面 | 何时使用 | 不必做什么 |
|---|---|---|
| 概览 | 查看工程、连接、质量、任务摘要 | 不用反复触发几何扫描 |
| 连接工程 | 第一次连接、切换目标 Mesh 系统 | 不需要新建 ANSYS 工程 |
| 局部细化 | 命名组尺寸、完整几何扫描、Sizing 管理 | 不需要重新命名 inlet/outlet |
| 质量报告 | 更新结果、标记异常单元、生成局部方案 | 不要把 Worksheet 警告数当成固定偏度阈值计数 |
| 质量分析 | 历史趋势、对比、导出报告 | 不会自动重扫 ANSYS |
| 设置与维护 | 数据、诊断、维护类操作 | 不要通过删除整个 Data 文件夹升级 |

## 4. 看懂四个常见网格指标

| 指标 | 更好的一侧 | 看它的目的 |
|---|---|---|
| 最大 Skewness（偏度） | **更接近 0** | 识别最差的偏斜单元 |
| 最小 Element Quality | **更接近 1** | 检查局部最差单元的形状 |
| 平均 Element Quality | **更接近 1** | 观察整体质量，但不能替代最小值 |
| 最小 Orthogonal Quality | **更接近 1** | 辅助判断 CFD 网格正交性，需真实数据来源 |

P95 偏度与 `Skewness > 0.90 / > 0.95` 的单元数量可以辅助评估改善程度，但如果 ACT 没有取得有效数据，软件应显示缺失原因，不允许用估算值冒充真实测量值。

## 5. 常见问题

<details>
<summary><strong>程序显示连接失败，怎么办？</strong></summary>

检查 Workbench 和 Meshing 是否已打开、是否选择正确的目标 Mesh 系统；查看任务中心及诊断信息。不要为了连接重新创建工程，也不要清理现有任务锁。
</details>

<details>
<summary><strong>为什么某些指标一直显示“未取得”？</strong></summary>

Meshing ACT 的接口能力与 Fluent 不同。普通检查可能只有全局偏度或 Element Quality。深度采集与 Worksheet 后备方案仍需在你的 ANSYS 版本中验证；无有效数据时不会推算。
</details>

<details>
<summary><strong>为什么区间很大时只标记一部分单元？</strong></summary>

为控制内存，自适应筛选会优先处理低质量端可安全分析的部分，不等于全区间都完成了处理。必须查看任务回执中的实际处理区间和未处理范围。
</details>

<details>
<summary><strong>为什么发布按钮是灰色？</strong></summary>

检查目标选择、完整几何核验、现有 Sizing 冲突、人工确认、批次数量和任务状态。可查看按钮的禁用原因，**不要直接绕过安全检查**。
</details>

<details>
<summary><strong>升级新版要删除 C 盘文件夹吗？</strong></summary>

**不要删除。** 关闭正在运行的程序，备份数据目录并替换新 EXE。该目录可能含历史质量快照、任务回执、Sizing 记录；删除会造成历史数据丢失。
</details>

<details>
<summary><strong>发布 Sizing 后网格会立刻改变吗？</strong></summary>

不会。发布只是修改 Meshing 的局部网格控制；是否重新生成网格由用户单独决定。重划后应重新检查总单元数与网格质量。
</details>

## 6. 怎么确认优化真的有效？

建议记录每一轮的：**总单元数、最大偏度、最小 Element Quality、平均 Element Quality、异常单元计数（可用时）、网格生成耗时与内存情况**。只有在工程/几何身份、质量指标采集口径适合比较时，才能正式认定优化效果。

也要检查修改是否带来新的局部坏单元：平均 Element Quality 升高，不一定意味着最差的单元变好了。
