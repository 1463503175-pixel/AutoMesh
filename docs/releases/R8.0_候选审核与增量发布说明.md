# AutoMesh R8.0：全量候选 · 手动勾选 · 安全增量发布

本版按用户在 R7.8～R7.9 后明确的目标修改 **R7.9 完整源码**，没有修改当前 ANSYS 工程，也没有打开第二个 Workbench 或 Meshing。此次提供 **Windows x64 EXE＋完整源码**，并保留旧版 Workbench/ACT 接口。此次交付属于代码级/模拟测试完成，**不宣称已在用户真实 10,055,480 单元工程中完成发布验收**。

## 一、主要新增

1. **全部候选**：不再在第 24 个局部区域后截断。`warning_refinement.py` 将可安全分簇的所有候选记录在一个预览报告中；当前仍设 **最多 4096 个待分析单元**、**最多 4096 个候选**的资源保护上限，超过时拒绝并报告原因，绝不悄悄截断。
2. **偏度排序**：仅当 ACT 元素对象真实暴露可转换为 [0,1] 数值的 `Skewness` 时，计算该区域所有目标单元的最大、平均偏度，默认按**最大偏度降序**；无法读取的候选明确显示“未取得”，随后按目标单元数量辅助排序。**尚未核实 ANSYS 2024 R2 原生接口在用户环境能否提供每个元素的该属性，不能宣称真实数据总能排序。**
3. **原生勾选界面**：在质量页点击“审核发布 Sizing”，进入 Win32 ListView 可滚动审核页，展示排序、最大偏度、目标单元数量、Body、球半径、尺寸、预算代理、是否已发布。**默认不勾选任何候选**；可取消勾选、查看影响域 HTML；正式发布需要勾选、查看范围、明确的人工风险确认、现有任务安全检查和最终确认。
4. **预算与碰撞**：保留单影响域 ≤64 个目标单元、半径 ≤12 mm、总尺寸/体积³ 预算代理 ≤120000，每次选中时计入之前已发布的 AutoMesh Sizing。近乎重合的同 Body 影响域拒绝重复发布，普通相交会提示人工复核；**预算代理不是实际新增网格数，也不是可精确预测的内存使用量**。
5. **分批发布**：仅发布明确勾选的候选 ID，Worker 复核其属于当前工程及预览方案，并与实时单元坐标/连接信息校验；每批最多 6 个 Sizing + 坐标系。每批完成后保存对象 ID、几何参数及候选 ID。下一次打开审核列表，已经发布的候选显示“已发布·不可重复”，其余仍留在队列；例如 200 个候选可先发布 15 个，下一次再选择其它 15 个。
6. **失败恢复与旧版兼容**：批次失败尝试回滚本批，新旧批次的实际回执区别记录；以前成功的批次不随新一批失败删除。R7.9 无候选 ID 的旧控制只有在 Body/球心/半径/尺寸均能精确匹配时才认可，否则停止等待人工核验。检测历史已发布影响球与当前预览不匹配时禁止叠加。精确支持 R7.9 发布版脚本哈希安全升级；人工修改的 Worker 不会被擅自覆盖。
7. **绝不重新划网**：只读预览不修改任何 Sizing；审核发布只创建新 Sphere of Influence Sizing 与坐标系；**不调用 GenerateMesh、不删除原网格、不启动 Fluent 或新的 ANSYS 会话**。

## 二、主流程

质量报告 → 设置偏度 0.90–1.00 → 标记真实网格单元 → 生成完整分簇候选 → 点击“审核发布 Sizing” → 手动勾选 → 查看具体范围 → 核实晶圆净空与现有 Sizing → 勾选人工风险确认 → 最终确认 → Worker 分批发布 → 可继续处理剩余候选。

**当前工程的 297 个是筛选出的网格元素数，不等于候选区域数。** 分簇的实际数量需再次由用户自己的 ANSYS ACT 读取，不能用模拟数据猜测。每簇若无法唯一匹配几何 Body，则单独排除并报告原因。

## 三、明确未完成/需实机核对

- ANSYS 2024 R2 ACT 是否暴露 `IElement.Skewness` 的可读数值：**尚未实机核实**；没有则展示“未取得”，不能满足全部真实最大偏度排序的最终要求。可在实际环境取得反例后再研究官方数据表或可信质量数据接口。
- 候选数大于 4096、目标单元数大于 4096 的跨批流式聚类尚未完成；这是内存安全防线，不是 24 候选截断。
- 晶圆间真实净空无法由当前 Body + 节点关联证明，须人工审核。相交影响域可能影响邻近面，不能仅靠预算认为安全。
- Windows 125%/150% DPI、原生 ListView 勾选、焦点、滚动及自动连接需要用户**实机验收**；现有测试为 Go/Mock ACT + Windows 交叉编译，不是现场确认。
- 不包含自动网格重划及前后偏度 CV 统计/自动选优；下一步单独授权。

## 四、回归验收

- 200 个模拟 ACT 元素（各形成单独候选）得到 200 条记录；如果模拟公开真实 Skewness 属性则能按最大偏度降序；缺失属性会明确标记未知。
- 默认无审核清单，发布被阻断；人工选取 15 个、分 3 批发布；第二次另选 15 个继续，历史控件无重复。
- 第二批失败时保留第一批 6 个已提交控件和持久回执；未发布候选继续可选；原网格未生成。
- 验证 R7.9 无候选 ID 的旧控制迁移、网格单元数变化拒绝、人工修改保护、近重复影响域识别、最大偏度 HTML 正确格式。
- Python 和 Go 旧回归全部通过；Windows EXE 交叉编译通过，并从发行包独立解压重编核对哈希。

**升级注意**：请先保存 Workbench 工程，确认旧 AutoMesh 任务确实结束，备份工程及任务数据；关闭 R7.9 AutoMesh 进程，但保持 Workbench/Meshing 会话。将新版解压到独立英文文件夹运行。第一次使用请重新生成候选预览，以获得稳定候选 ID；不要直接发布 R7.9 历史预览。
