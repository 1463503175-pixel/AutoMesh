# AutoMesh R8.0.4 新手使用手册

> 面向第一次使用 AutoMesh 的用户。本文按“准备环境 → 连接工程 → 只读扫描 → 选择细化路线 → 审核 → 发布 → 重新检查”的顺序说明软件操作，并解释关键内部逻辑。
>
> **适用版本：** AutoMesh R8.0.4；目标环境为 Windows x64 + ANSYS Workbench / Meshing 2024 R2。

## 0. 先理解 AutoMesh 是什么

AutoMesh 是一个辅助 ANSYS Meshing 的网格检查与局部细化工具。它不替代 ANSYS Meshing，而是在你已经打开的 Workbench/Meshing 工程上，帮助你：

- 读取当前工程的几何体、几何面、单位、Named Selection、网格参数和已有 Sizing。
- 读取当前网格的质量指标，辅助定位失败单元、警告单元和指定偏度范围内的单元。
- 根据几何面特征或网格警告单元，整理可审核的局部细化建议。
- 将经过确认的建议转成 ANSYS 原生 Named Selection、Sizing 或 Sphere of Influence Sizing。
- 保存任务状态、诊断报告和发布记录，支持分批优化以及 R8.0.4 的历史 Sizing 接管。

**它不是一键保证网格合格的软件。** 自动推荐是候选方案，必须由使用者检查几何作用域、局部净空、已有控制和网格质量；最终 CFD 网格仍需在 Meshing / Fluent 中验证。

### AutoMesh 不负责什么

- 不负责 CAD 建模、修复几何或修改晶圆/零件结构。
- 不负责启动 Fluent、设置物理模型、求解 CFD 或判断沉积均匀性。
- 不会仅凭偏度推算正交质量，也不会把无法读取的指标伪装成数值。
- 不会默认启动第二个 Workbench/Meshing、打开新工程或创建新系统。
- 局部 Sizing 发布不等于重新划分网格；发布后必须在 Meshing 中检查并按需重新生成网格。

## 1. 第一次运行前的准备

### 1.1 必备环境

| 项目 | 要求 / 说明 |
|---|---|
| 操作系统 | Windows x64 |
| ANSYS | 已安装 ANSYS Workbench / Meshing 2024 R2 |
| 工程 | 已打开需要处理的现有 Workbench 工程 |
| Meshing | 已打开目标系统的 Mesh 编辑器 |
| Python | Python 3；程序会检查可用解释器 |
| PyWorkbench | Python 环境中可导入 **ansys.workbench.core** |
| 网络 | AutoMesh 与 Workbench 通过本机回环地址连接，不要求公网服务 |

程序会检查 **py -3.11**、**py -3.12**、**py -3.10**、**py -3** 以及常见 Python 安装位置，并验证 **ansys.workbench.core** 是否能导入。若初始化提示缺少 Python 或 PyWorkbench，请按提示修复对应 Python 环境；不要只因为 **python** 命令不可用就判断电脑没有安装 Python。

### 1.2 正确打开 ANSYS

1. 启动 ANSYS Workbench 2024 R2。
2. 打开你要处理的现有工程。
3. 在 Project Schematic 中双击目标系统的 **Mesh** 单元，确保 Meshing 编辑器已经打开。
4. 检查当前工程和目标 Mesh 系统正确后，再启动 AutoMesh。

> AutoMesh 需要复用这个已经打开的会话。不要为了连接 AutoMesh 另外新建一个 Workbench 工程，也不要在多个工程之间随意切换后继续使用旧扫描结果。

### 1.3 Workbench 连接服务

AutoMesh 会先查找当前 Workbench 的脚本服务，并验证返回的系统列表。若当前会话没有脚本服务：

- 优先让 AutoMesh 在能够唯一识别的**现有 Workbench**中，通过 Windows UI Automation 定位脚本命令窗口并尝试执行 **StartServer()**。
- 如果自动启动服务没有成功，可在现有 Workbench 中打开 **File > Scripting > Open Command Window**，输入 **StartServer()** 并回车，然后回到 AutoMesh 点击“自动查找并连接”。
- 若界面无法唯一确认当前 Workbench 或命令窗口，程序会停止，不会猜测窗口或启动第二个 Workbench。

### 1.4 数据目录

AutoMesh 的任务文件、脚本、日志、扫描快照、用户选择和报告保存在独立工作目录，不放在 ANSYS 工程几何中。默认优先使用：

- **C:\ProgramData\AutoMesh2024R2\Data**
- 若不可用，再尝试 **%PUBLIC%\Documents\AutoMesh2024R2\Data**

也可以在“更多设置”中迁移到其他盘。数据目录必须是**绝对路径且只使用 ASCII 英文字符**，例如 **D:\AutoMeshData**。这是为了降低 ACT / IronPython 对中文路径的兼容风险。迁移时旧目录会保留；迁移期间不要运行任务。

## 2. 五个主页面分别做什么

左侧导航依次为：**概览、连接工程、局部细化、质量报告、更多设置**。此外，质量报告中的警告区审核会打开一个独立的“局部优化候选”页面。

### 2.1 概览

概览用于确认当前工程身份和整体状态，不是细化控制的编辑页面。

| 区域 | 显示内容 | 如何理解 |
|---|---|---|
| 当前工程 | 工程路径末端名称、当前 Mesh 系统 | 确认操作对象没有选错 |
| 几何规模 | Body 数量、Face 数量 | 只读扫描读取到的几何规模 |
| 显示单位 | Meshing 显示单位、CAD 几何底层单位 | 程序会把内部几何尺寸换算为 mm |
| 识别摘要 | 有效面积面、候选面积组、未列出组 | 几何分类的统计，不代表已经创建 Sizing |
| 网格参数 | 参考尺寸（mm） | 推荐算法使用的参考值，不一定等于当前全局 Element Size |
| 任务状态 | 当前阶段、进度、详情 | 查看任务是否正在运行、是否完成或报错 |
| 网格质量 | 单元数、最大偏度、质量状态 | 显示已取得的质量结果；旧结果可能需要重新检查 |

**主要按钮**

- **只读扫描：** 读取当前工程几何、命名、网格参数和已有控制，并生成初步几何候选。不会生成网格，也不会发布 Sizing。
- **查看报告：** 跳转到质量报告页面。
- **打开文件夹：** 打开 AutoMesh 工作数据目录。

**参考尺寸与全局覆盖**

- 参考尺寸默认值为 **12 mm**。它主要作为几何分类和推荐尺寸的基准，不应直接当作当前 Meshing 全局尺寸。
- “使用参考尺寸覆盖全局”默认关闭。关闭时，AutoMesh 不修改全局 Element Size。
- 只有在明确理解影响、检查全局参数并通过程序校验后，才考虑启用全局覆盖。已有网格时，程序会限制覆盖全局尺寸的操作；按现有 Named Selection 发布局部 Sizing 的路径要求关闭该选项。
- 所有局部尺寸输入统一使用 mm。

### 2.2 连接工程

此页完成 AutoMesh 与现有 Workbench / Mesh 系统的连接。

| 控件 | 用途 |
|---|---|
| 手动端口（可选） | 只有已知 Workbench 脚本服务端口时才填写；一般保持“自动” |
| 自动查找并连接 | 搜索并验证本机 Workbench 脚本服务 |
| 重新检查初始化 | 重新检查 AutoMesh 内部 Worker、脚本文件和 Python 连接环境；不修改 ANSYS 工程 |
| 检查任务状态 | 查看上一次任务是否已由 Meshing 明确结束 |
| 系统名称列表 | 选择当前 Workbench 工程中的目标 Mesh 系统 |
| 我已在 Workbench 中打开目标 Meshing 编辑器 | 明确确认编辑器已经打开；未勾选时不会向目标系统发送修改命令 |

**推荐操作顺序**

1. 点击“自动查找并连接”。
2. 等待系统列表返回。
3. 选择正确的 Mesh 系统。
4. 确认该系统的 Meshing 编辑器已经打开。
5. 勾选“我已在 Workbench 中打开目标 Meshing 编辑器”。
6. 回到概览，点击“只读扫描”。

连接成功只表示脚本服务和系统列表通过验证，不代表网格质量已经检查，也不代表 Sizing 已发布。

### 2.3 局部细化

此页的核心是：**复用 Meshing 里已经存在的 Named Selection，给选中的命名组设置尺寸并绑定 Sizing。** 它不是一个让用户在 AutoMesh 中重新用鼠标选择几何面的 CAD 选择器。

页面包含：

- **命名组列表：** 显示当前 Meshing 中的 Named Selection，以及按推荐尺寸整理的分组。
- **只看 AutoMesh / 显示全部命名：** 在 AutoMesh 辅助命名和全部命名之间切换。
- **刷新命名：** 重新读取当前 Meshing 命名树；几何或命名发生变化后应先刷新。
- **推荐并归组：** 根据已有命名组对应几何面的面积、面型和参考尺寸，重新计算初步推荐并按相近尺寸归组。它会重置本页尚未发布的人工尺寸草稿，执行前要确认。
- **启用此命名组：** 控制当前选中的单个命名或整组是否参与下一次发布。
- **单项尺寸 / 保存单项尺寸：** 只修改当前单个命名的目标尺寸，不影响同组其他命名。
- **整组尺寸 / 整组设置：** 统一修改当前分组内各命名的目标尺寸；保存尺寸不会自动改变原有启用状态。
- **自动命名（可选）：** 根据本轮几何候选创建 AutoMesh 辅助 Named Selection（通常以 **AM_** 开头）。这一步只创建命名，不创建 Sizing，也不生成网格。完成后应回到 Meshing 树检查作用面，再重新扫描。
- **发布命名 Sizing：** 对已勾选的现有 Named Selection 创建或同步原生 Sizing。它不会调用 GenerateMesh。
- **核对全局参数：** 显示上次扫描读取到的全局尺寸、最大尺寸、增长率、自适应、曲率、邻近、物理偏好、求解器偏好和单元阶次等信息。
- **审核后生成网格：** 这是单独的受控重划步骤，不等于“发布 Sizing”。仅在已完成受控命名 / Sizing 准备并通过检查后使用。

**命名组尺寸推荐是启发式建议，不是物理定律。** 当前实现会读取面面积并换算为 mm²，计算命名组面积中位数，结合曲面比例和少量明确的命名线索给出初始尺寸；例如，简单小圆柱面组可能获得较高的自动启用资格，而其他组需要人工审核。**inlet / outlet** 不进入自动推荐。面积本身不能证明一个面在物理上属于晶圆、孔或流道。

**发布注意事项**

- 单次按命名发布最多 40 个 Named Selection，数量较多时分批处理。
- 发布前会检查当前工程、几何指纹、命名作用面、已有 Sizing 和资源预算。
- 已有网格时，新增 Sizing 可能使当前网格失效；请先保存工程。AutoMesh 不会在这一步自动清网格或重划。
- 对于已确认由 AutoMesh 创建的旧 Sizing，取消勾选后可能会执行 Suppress（停用但不删除）；重新勾选可恢复。人工创建的 Sizing 不会被自动修改。
- 发布后到 Meshing 树中检查实际作用域、尺寸和启用状态。

### 2.4 质量报告

此页用于读取质量、标记质量问题并启动警告区局部优化。

**质量指标**

- **单元数 / 节点数：** 当前 Mesh 的实际统计。
- **偏度 Skewness：** 读取 ACT 当前网格的最小值、最大值和平均值（接口可用时）。
- **正交质量 Orthogonal Quality：** 仅在当前 ACT 接口真实提供并成功读取时显示。
- **Worksheet 失败 / 警告数量：** 尝试读取 ANSYS Meshing 官方 Quality Worksheet 结果。
- **质量判断：** 根据已取得的真实指标给出提示；缺少必要指标时不会假装通过。

特别注意：某些 ACT 会话不开放 **OrthogonalQuality** 枚举。此时报告会显示“未提供 / 需 Meshing 或 Fluent 核验”，这不是正交质量为 0。**不能用 1 - 最大偏度或其他换算代替正交质量。**

**质量报告页按钮**

| 按钮 / 控件 | 做什么 | 是否修改网格 |
|---|---|---|
| 只读质量检查 | 读取当前 Mesh 的质量指标 | 否 |
| 标记失败单元 | 调用 ANSYS 官方 Worksheet 标记失败元素 | 不改网格；会增加/更新选择组 |
| 按默认警告标记 | 调用官方 Worksheet 标记警告元素 | 不改网格；会增加/更新选择组 |
| 偏度范围 | 设置自定义下限和上限，范围需满足 **0 ≤ 下限 < 上限 ≤ 1** | 否 |
| 标记所选偏度 | 按输入区间创建当前网格的 Mesh Element 选择组；默认值为 0.90–1.00 | 不改网格；会改变命名选择树 |
| 风险抽样诊断 | 对部分四面体单元做辅助抽样，最多检查 6000 个样本 | 否；不是全网格穷举 |
| 生成局部方案 | 读取刚标记的警告单元，分析空间簇和局部球形影响域 | 否 |
| 查看影响范围 | 打开本轮候选的 HTML 影响域报告 | 否 |
| 审核发布 Sizing | 打开候选勾选审核页面 | 打开页面本身不修改网格 |

**警告标记和偏度范围标记不是同一件事：**

- “按默认警告标记”使用 ANSYS 当前 Quality Worksheet 的警告规则。
- “标记所选偏度”使用你输入的上下限筛选单元，不会修改 ANSYS 原有 Worksheet 阈值。
- 新网格生成后，原来的单元 ID 可能变化；旧标记不能直接用于新网格，必须重新标记。

### 2.5 局部优化候选审核页

点击“审核发布 Sizing”后，AutoMesh 会打开候选列表。**默认不勾选任何候选。**

列表字段：

| 字段 | 含义 |
|---|---|
| 区域 | 候选区域编号 |
| 最大偏度 | ACT 能读取时显示该簇实测最大偏度；否则显示“未取得” |
| 目标单元 | 该候选所覆盖的已标记单元数量，不是预计生成的网格单元总数 |
| Body | 候选对应的几何 Body ID |
| 球半径（mm） | 局部 Sphere of Influence 的影响半径 |
| 尺寸（mm） | 球形影响域内拟使用的目标单元尺寸 |
| 预算代理 | 用于安全限制的代理量，不是实际新增单元数 |
| 状态 | 待审核、已发布、与历史 Sizing 相交 / 近重合等 |

**必须按以下顺序审核**

1. 先点击“查看全部影响域”，打开本轮 HTML 详细报告。
2. 逐项核对 Body、球心坐标、球半径、目标尺寸、覆盖单元 ID。
3. 结合实际模型检查候选球是否覆盖了正确的缺陷位置，尤其核对晶圆片间净空、舟体和邻近结构。
4. 返回候选页，只勾选本轮确实需要发布的候选。
5. 勾选“我已核查所选区域的几何位置、晶圆间隙和现有 Sizing”。
6. 检查累计预算、候选相交提示和历史 Sizing 状态。
7. 点击“审核所选并发布”，并在最终确认窗口再次确认。

候选影响球近乎重合时会禁止重复发布；普通相交需要打开详情并人工核查。历史 Sizing 会保留并计入累计预算。若历史控制清单无法完整核验，页面可以继续只读查看，但发布会被锁定。

### 2.6 更多设置

| 功能 | 说明 |
|---|---|
| 单独导出 .msh | 将当前已生成的网格导出为 Fluent .msh 文件 |
| 工作数据目录 | 查看或迁移任务、日志、扫描快照、用户选择和报告所在目录 |

导出 .msh 时需要填写英文绝对路径，例如 **D:\MeshExport\model.msh**。若目标文件已存在，AutoMesh 会拒绝覆盖。导出前会检查 **inlet / outlet** 的 Send to Solver 等基础条件，但**导出成功不代表 Fluent 网格质量合格**。导出后仍需在 Fluent 中检查边界分区、正交质量、偏度和实际网格拓扑。

## 3. 两条主要局部细化路线

这两条路线的输入对象和控制类型不同，不要混为一谈。

### 路线 A：基于现有 Named Selection 的局部细化

适合已经在 Meshing 中建立了晶圆面、孔、间隙、挡板或其他局部命名组的工程。

1. 连接工程并完成只读扫描。
2. 进入“局部细化”，刷新命名。
3. 检查命名组的实际面范围；需要时点击“推荐并归组”。
4. 选择单项或整组，决定启用状态并输入尺寸（mm）。
5. 可选：点击“自动命名（可选）”创建辅助命名；创建后重新扫描并检查。
6. 点击“发布命名 Sizing”，确认发布。
7. 回到 Meshing 树检查每个 Sizing 的作用域、尺寸和状态。
8. 保存工程。若需要重新划分网格，再单独执行“审核后生成网格”，确认旧网格可能被清除后再继续。
9. 重新执行质量检查，并在 Fluent 中完成 CFD 网格复核。

这条路线使用现有 Named Selection 作为几何作用域，控制粒度取决于原有命名是否准确。

### 路线 B：基于质量警告单元的自动分簇细化

适合已经生成网格、希望针对高偏度或 Worksheet 警告单元建立局部影响域的工程。

1. 在“质量报告”中点击“只读质量检查”。
2. 选择一种标记来源：
   - 使用官方 Worksheet：“按默认警告标记”；
   - 使用自定义偏度区间：输入下限和上限，点击“标记所选偏度”。
3. 点击“生成局部方案”。此阶段只读取当前标记单元并计算候选，不创建 Sizing。
4. 点击“查看影响范围”，检查 HTML 报告中的候选 Body、球心、半径、目标尺寸、单元 ID、预算和历史 Sizing。
5. 点击“审核发布 Sizing”，在候选页逐项勾选需要处理的区域。
6. 确认片间净空和历史控制关系，勾选人工审核确认。
7. 点击“审核所选并发布”。AutoMesh 只为本次明确勾选的候选创建可编辑的球形 Sizing 和对应坐标系。
8. 回到 Meshing 树检查 **AutoMesh_QR_*** 与 **AutoMesh_QR_CS_*** 控件，保存工程。
9. 本次发布不会清网格或调用 GenerateMesh。需要重新划分时，在 Meshing 中按工程实际情况单独执行并确认。
10. 新网格生成后，重新检查质量、重新标记当前网格的偏度范围、重新生成本轮方案，再进入下一轮审核。

## 4. 软件内部是怎样工作的

### 4.1 程序架构

AutoMesh 不是通过截图识别 ANSYS 窗口位置来操作软件。主要链路如下：

~~~text
AutoMesh.exe（Go 原生 Windows 桌面界面）
        │
        ├── 创建任务 ID、任务文件、状态锁和进度记录
        │
        ▼
Python / PyWorkbench 连接桥
~~~

**各部分职责**

- **Go 桌面程序：** 页面、按钮、状态管理、任务 ID、任务锁、报告展示和安全确认。
- **Python / PyWorkbench：** 连接本机现有 Workbench 脚本服务，列出系统并把任务送到选定的 Mesh 系统。
- **ACT / IronPython Worker：** 在当前 Meshing 会话内读取模型、执行 ANSYS 原生 API、生成质量选择组或创建 Sizing。
- **本地工作目录：** 保存 Worker 脚本、扫描快照、任务 JSON、进度、结果、候选方案、历史发布清单和报告。

### 4.2 只读扫描阶段

扫描会读取当前工程的：

- 工程路径和几何身份；
- Body ID、名称、体积和面数量；
- Face ID、所属 Body、面积、面型，以及可读取时的质心、包围盒、法向和圆柱半径；
- 几何单位、Meshing 显示单位；
- Named Selection 名称和实际几何面 ID；
- 当前 Mesh 单元数、节点数、全局尺寸、最大尺寸、增长率、自适应、曲率、邻近等可读取参数；
- 当前 Mesh 树中已有控制的类型、作用域和尺寸等信息。

程序会把几何单位统一换算为 mm，并生成几何指纹。后续任务会核对工程和几何指纹，防止把旧工程、旧几何或旧扫描结果误用于当前模型。

只读扫描本身不会调用 GenerateMesh，也不会主动清除已有网格。

### 4.3 Named Selection 推荐逻辑

局部细化页的推荐不是简单按名称猜测，也不是直接根据面积断言几何功能。程序会：

1. 读取 Named Selection 实际包含的面 ID。
2. 将面 ID 映射到本轮扫描的 Face 信息。
3. 读取面面积并换算为 mm²。
4. 计算该命名组的面积中位数。
5. 结合曲面比例、参考尺寸和少量明确的命名线索，给出保守初始尺寸。
6. 将推荐尺寸相近的命名组归为一组，供用户批量设置。
7. 对重叠作用面、无法读取的面和缺少功能证据的组保留审核要求。

例如，当前推荐逻辑会以面积中位数的平方根乘以保守系数作为初始估计，再限制在参考尺寸范围内；曲面较多或名称中明确包含晶圆线索时会进一步收紧建议。**这只是网格尺寸启发式，不等于该处物理上一定需要这个尺寸。**

### 4.4 警告单元如何变成局部球形候选

警告区路线比几何推荐多了一层网格单元到几何 Body 的映射：

1. 从 ANSYS Worksheet 创建的当前网格元素选择组读取单元 ID。
2. 核对工程路径、几何指纹、网格单元总数、选择组对象 ID 和元素 ID 列表，确认标记仍属于当前网格。
3. 从当前 MeshData 读取可用的单元节点、坐标、偏度和所属几何信息。
4. 在同一几何 Body 内，依据共享节点关系和空间邻近关系建立局部连通簇。
5. 将过长或过大的连通区域进一步拆成多个可审核的小簇，而不是用一个巨大球覆盖全部缺陷。
6. 为每个簇计算球心、球半径、目标单元尺寸、覆盖单元 ID 和预算代理。
7. 将无法安全映射、影响半径过大、已有更细控制或预算不合适的区域放入拒绝原因列表。

当前实现的主要安全限制：

| 限制 | 当前规则 | 作用 |
|---|---:|---|
| 单簇标记单元上限 | 64 个 | 防止一个候选覆盖过大区域 |
| 单个球形影响半径 | 不超过 12 mm | 限制局部影响范围 |
| 目标单元尺寸 | 0.5–5 mm | 限制候选尺寸范围 |
| 单次分析标记单元上限 | 4096 个 | 超出时要求缩小范围或分批标记 |
| 候选记录上限 | 4096 条 | 防止无界候选清单 |
| 每批发布数量 | 最多 6 个 | 分批创建和核验控件 |
| 累计预算代理上限 | 120000 | 限制历史与新增球形控制的累计代理量 |

候选目标尺寸根据簇内单元尺度计算，并限制在 0.5–5 mm；已有更细的 Sizing 会参与约束，避免自动建议覆盖手工更细控制。

**预算代理不是实际网格单元数、不是新增单元数，也不是精确内存预测。** 球形候选的代理量与影响球体积和目标尺寸的三次方关系有关，仅作为保守筛选阈值。不要把 120000 理解为“将增加 12 万个网格单元”。

### 4.5 发布前为什么还要重新核验

预览结果不是永久有效的授权。真正发布前，ACT 会重新读取当前模型并复核：

- 当前工程和几何身份；
- 当前警告标记和网格单元数；
- 候选几何、Body、球心、半径、目标尺寸；
- 当前已存在的 Sizing；
- 已有控制的作用域、尺寸和历史身份；
- 坐标系与 Sizing 对象的对应关系；
- 近重合影响球、累计预算和本轮是否重复发布。

只有本次明确勾选且通过核验的候选才会创建 Sizing。创建后还会回读控件类型、Body 作用域、尺寸、半径和球心，确认写入值与审核方案一致。

### 4.6 R8.0.4 的历史 Sizing 接管逻辑

R8.0.3 的一个问题是：重新划分网格后，单元 ID 会变化，旧候选 ID 也可能不再出现在新网格中。旧逻辑错误地把候选 ID 当作历史 Sizing 的唯一身份，导致连续优化被锁定。

R8.0.4 将身份分开：

- **历史 Sizing 身份：** 当前 ACT 模型树里的真实 Sizing 对象、对象 ID、Body 作用域、坐标系对象 ID、球心、半径、目标尺寸和启用状态。
- **本轮候选身份：** 当前网格中被标记的单元、分簇结果和当前方案的 candidate ID。

因此，旧网格候选 ID 不再是继续优化的前置条件。新网格可以生成新候选；历史 Sizing 仍从当前模型树重新读取、核验并计入累计预算。

接管不是无条件认领。若历史 Sizing 被改名、停用、修改作用域、修改尺寸或球心，坐标系无法唯一配对，或对象类型与范围无法验证，程序会锁定发布并要求人工检查。**接管只建立审计记录，不会移动、删除、覆盖或 Suppress 历史控件。**

### 4.7 任务锁、进度和异常恢复

每个任务都有独立 Job ID，并保存任务请求、进度心跳和终态结果。程序同一时间只允许一个需要修改 Meshing 的任务，避免重复提交。

- 若任务仍在执行，界面会阻止再次提交。
- 若 Workbench 调用超时，但无法确认 ACT 已停止，程序保留任务锁，不把超时当成任务结束。
- “请求停止任务”是协作式停止，只能在 ACT 可响应的安全检查点停止；不能保证立即终止正在执行的 GenerateMesh，也不会强制结束 Meshing 进程。
- “解除已停止任务占用”属于危险恢复操作。必须先在 ANSYS 中确认旧任务确实停止，再按提示人工确认；不能仅凭 AutoMesh 界面没有响应就清锁。

## 5. 哪些操作会修改 ANSYS，哪些不会

| 操作 | 读取数据 | 改变 Named Selection | 创建 / 修改 Sizing | 清除 / 生成网格 |
|---|---:|---:|---:|---:|
| 连接 Workbench | 是 | 否 | 否 | 否 |
| 只读扫描 | 是 | 否 | 否 | 否 |
| 只读质量检查 | 是 | 否 | 否 | 否 |
| 风险抽样诊断 | 是 | 否 | 否 | 否 |
| 标记失败 / 警告 / 偏度 | 是 | 是，创建元素选择组 | 否 | 否 |
| 生成警告区局部方案 | 是 | 否 | 否 | 否 |
| 查看影响域报告 | 读取本地方案 | 否 | 否 | 否 |
| 发布自动命名 | 是 | 是，创建辅助命名 | 否 | 否 |

## 7. 常见问题

### 7.1 点击连接后没有找到 Workbench

1. 确认 Workbench 2024 R2 工程仍打开。
2. 确认目标 Mesh 编辑器已经打开。
3. 在现有 Workbench 的 Scripting Command Window 执行 **StartServer()**。
4. 回到 AutoMesh 再点“自动查找并连接”。
5. 若仍失败，点“重新检查初始化”，查看 Python / PyWorkbench 诊断；不要反复启动多个 Workbench。

### 7.2 Python 命令找不到，但电脑明明安装了 Python

AutoMesh 不只检查 **python** 命令，还会检查 Windows **py** Launcher 和常见安装目录，并实际执行 **import ansys.workbench.core**。关键是被 AutoMesh 选中的解释器能否导入 PyWorkbench，而不是开始菜单里是否存在 Python 图标。

### 7.3 扫描后几何或命名变了

重新执行“只读扫描”。旧快照中的面 ID、命名作用域或几何指纹可能已经失效，不要继续使用旧方案发布。

### 7.4 发布 Sizing 后网格显示失效

这是因为新增 Sizing 可能使现有网格需要重新生成。发布 Sizing 不等于重新划分；先保存工程，核对 Sizing 作用域，再单独执行受控重划。

### 7.5 为什么正交质量显示未获取

当前 ACT 会话可能没有开放正交质量枚举，或读取失败。AutoMesh 不会用偏度换算。请在 Meshing 原生质量统计或 Fluent Mesh Quality 中核验。

### 7.6 为什么警告区候选显示“未取得最大偏度”

某些 ACT 数据读取路径可以获得元素 ID 和坐标，但无法获得每个元素的偏度数值。此时程序会明确显示“未取得”，不会将警告等级或候选排序伪装成实测偏度。

### 7.7 为什么新网格后旧标记不能继续用

重新划分后，单元 ID 和网格数量可能变化。必须对当前网格重新标记偏度 / 警告单元并生成新方案。R8.0.4 会保留并核验历史 Sizing，但不会把旧网格元素 ID 当作新网格元素 ID。

### 7.8 为什么候选页能查看但不能发布

常见原因是历史 Sizing 清单不完整、对象身份不唯一、发布记录与当前工程不匹配，或存在近重合影响球。此时只读报告仍可查看，但发布锁定是有意的安全保护。先检查 Meshing 树和历史控件，不要为了消除提示直接删除旧 Sizing。

### 7.9 任务长时间没有进度

Workbench 的 SendCommand 可能在等待 ACT 执行。GenerateMesh 阶段没有可靠的原生百分比，界面不会伪造进度。先点“检查任务状态”查看同一 Job ID 的阶段与 ACT 心跳；在任务终态未确认前，不要再次提交同类修改任务。

### 7.10 预算超限或候选太多

- Named Selection 路线：减少启用的命名组、检查重叠作用域，或分批发布；一次最多 40 个。
- 警告区路线：减少本次勾选候选；每批最多 6 个。超过单次标记分析上限时，缩小偏度范围或分段标记。
- 预算代理不是实际内存和单元数，不应通过删除历史控制来绕过审核。
